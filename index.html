What you will learn

SQL Functions and their types

Understand what SQL functions are, and how Single-Row Functions differ from Multiple-Row Functions.

String and case conversion

Change text casing with LOWER and UPPER.

Character manipulation

Measure, trim, slice, search, and rebuild text with LEN, LTRIM, RTRIM, LEFT, RIGHT, SUBSTRING, CHARINDEX, REPLACE, REPLICATE, and SPACE.

Mathematical functions

Work with numbers using ABS, POWER, CEILING, FLOOR, and ROUND.

Agenda

  3. Quick visual summary and string functions overview
  4. Case conversion and query example

  7. SUBSTRING and CHARINDEX

  9. REPLACE and REPLICATE
